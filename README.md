# 末日倒计时：重生囤货 · Apocalypse Countdown (v0.1)

第三人称 3D 浏览器小游戏。前世被神秘组织抓去当实验体、最终启动基地自毁程序与之同归于尽的你，重生回到末日降临前三天——变卖资产、觉醒手镯空间、疯狂网购囤货，还要躲开保安老周的视线。

Three.js + Vite，无后端、无外部 API、无付费素材。所有模型、贴图、音效均为程序生成。

## 运行

```bash
npm install
npm run dev        # 本地开发，浏览器打开终端里显示的地址
npm run build      # 生产构建，输出到 dist/
npm run preview    # 本地预览构建结果
```

需要 Node.js 18+。

## 部署到 GitHub Pages

项目已包含 `.github/workflows/deploy.yml`，`vite.config.js` 使用 `base: './'`（相对路径），可部署在任意子路径下。

1. 在 GitHub 新建仓库，把本项目推送到 `main` 分支。
2. 仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. 每次推送到 `main` 会自动构建并发布，地址形如 `https://<用户名>.github.io/<仓库名>/`。

也可以手动：`npm run build`，然后把 `dist/` 目录内容上传到任意静态托管。

## 已实现内容

- 3D 公寓：卧室、客厅、厨房、玄关、12 楼楼道（快递暂存区）、电梯厅与保安室，无加载无缝移动；墙体与家具碰撞；静态网格按材质合并以减少 draw call。
- 第三人称角色：低多边形人物、行走/待机动画、朝移动方向转身；跟随相机带墙体遮挡检测。
- 开场演出（可跳过）：末日第 47 天的秘密实验基地：击碎实验舱、启动自毁程序、爆炸 → 生命体征消失 → 卧室醒来 → 系统激活 → 倒计时。
- 时间系统：72 小时倒计时；探索时 1 秒 = 2 游戏分钟，手机/对话/菜单打开时暂停；下单、贷款、等待、睡觉消耗时间；昼夜光照变化。
- 手机：银行（¥30,000 / ¥50,000 贷款，防重复领取，交易记录）、股票（¥20,000 持仓，一键清仓，防重复卖出）、外卖、购物（数量选择、购物车、确认支付、订单跟踪）、任务、消息、时钟（等待）。
- 手镯觉醒：发光手镯 + 粒子，镜头特写、滴血认主、觉醒特效，解锁 100 m³ 随身空间。
- 随身空间：按体积计算容量，分类（食物/饮水/医疗/工具/日用品/其他），堆叠，取出到现实世界（生成物资箱，可再次收回），容量严格限制、所有操作先改数据再播动画，杜绝复制。
- 配送：订单扣款 → 计时 → 通知 → 楼道出现 3D 快递堆（同类合并为少量箱子）→ 查看内容 → 收入空间（发光、粒子飞向手腕、缩小消失）。
- 保安老周：巡逻路线、视野扇形（地面可见，射线裁剪）、视距/视角/视线遮挡检测、怀疑度 0–100 四个等级；被看见收取快递会触发对峙，三种回应三种结局；平时可对话，台词随怀疑度变化。
- 7 个主线任务、妈妈的来电（转钱囤货 / 劝父母会合 / 简单叮嘱）、准备总结与章节结尾。
- LocalStorage 版本化存档（自动保存 + 手动保存），新游戏 / 继续 / 重置存档，损坏存档安全忽略。
- WebAudio 合成音效，桌面与移动端自适应 UI。

- 打包使用 esbuild 验证通过；`npm run build`（Vite）需要在你本地安装依赖后执行。

## 已知限制

- 人物为程序生成的简单低多边形模型，动画为程序化摆动，没有骨骼动画。
- 相机遮挡检测只针对墙体，高大家具（衣柜）偶尔会挡住视线。
- 保安对峙只在第一次被看见时触发完整对话，之后仅增加怀疑度和吐槽。
- 怀疑度达到“秘密可能暴露”目前只有警告，尚无后续剧情后果。
- 未在真机 iPhone / Android 上测试（仅用浏览器手机模式模拟触屏）。
